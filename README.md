# cafe-landing

가상의 동네 카페 "모닝빈"의 간단한 랜딩 페이지입니다. 순수 HTML과 CSS만으로 만들었고, 빌드 과정이나 외부 라이브러리가 필요 없습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 카페 소개, 오시는 길, 푸터) |
| `style.css` | 스타일 (색상 변수, 반응형 레이아웃) |

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 확인할 수 있습니다.

## 참고

- 카페 이름, 주소, 전화번호, 가격은 모두 예시 값입니다.
- 모바일 화면에 맞게 레이아웃이 자동으로 조정됩니다.
